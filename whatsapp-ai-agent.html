Case study — AI agent

WhatsApp AI agent for a Shopify store

An AI agent that answers customer questions and helps with orders on WhatsApp, connected to the store’s Shopify data. Built in n8n and tested in the cloud.

01 — The problem

The challenge

A Shopify store gets a steady stream of WhatsApp messages about products and orders. Answering each one by hand takes time, and replies slow down when the team is busy.

02 — The approach

How I built it

Each incoming message arrives through the WhatsApp Cloud API and starts an n8n workflow. An AI agent reads the question, looks up products and orders in Shopify, and writes a reply that goes back to the customer in the same chat.

03 — The result

What it does

Customers get an answer based on the store’s live data without waiting for someone to be online, and the team spends less time on repetitive questions.
